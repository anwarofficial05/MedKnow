# MedKnow — Healthcare Knowledge Management Portal

Please refer to the inner application directory [`healthcare_kmp/`](healthcare_kmp/) or deploy directly using the configurations provided.

### Quick Run:
```bash
cd healthcare_kmp
pip install -r requirements.txt
python app.py
```
